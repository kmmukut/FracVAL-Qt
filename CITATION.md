# Citation

## Original FracVAL methodology and software

If you use the FracVAL aggregate-generation methodology, please cite the
original publication:

```bibtex
@article{Moran2019FracVAL,
  author  = {Morán, J. and Fuentes, A. and Liu, F. and Yon, J.},
  title   = {FracVAL: An improved tunable algorithm of cluster-cluster aggregation for generation of fractal structures formed by polydisperse primary particles},
  journal = {Computer Physics Communications},
  volume  = {239},
  pages   = {225--237},
  year    = {2019},
  doi     = {10.1016/j.cpc.2019.01.015}
}
```

The original software/data release is:

```text
Morán, J.; Fuentes, A.; Liu, F.; Yon, J. (2019)
FracVAL: An improved tunable algorithm of cluster-cluster aggregation for
generation of fractal structures formed by polydisperse primary particles.
Mendeley Data, Version 1.
DOI: 10.17632/mgf8wdcsfb.1
```

## FracVAL-Qt

When publication or reproducibility practice calls for identifying the exact
software implementation used, please additionally cite the FracVAL-Qt
repository and the release/tag used in your work.

The `CITATION.cff` file is included so GitHub can expose a **Cite this
repository** action. The preferred scientific citation in that file is the
original Morán et al. FracVAL paper.

# Authors and contributors

## Original FracVAL

The original FracVAL Fortran software and scientific methodology were developed
by:

- J. Morán
- A. Fuentes
- F. Liu
- J. Yon

See `NOTICE.md` and `CITATION.md` for the original publication and software
release identifiers.

## FracVAL-Qt

FracVAL-Qt contains subsequent modernization and extension work. Contributors
to those changes are identified by this repository's Git history.

This separation is intentional: attribution for the original FracVAL work is
preserved without implying that the original authors authored or endorsed all
later Qt/Python modifications.
